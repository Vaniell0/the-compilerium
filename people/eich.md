## Known for

- Created JavaScript in 10 days in May 1995 at Netscape
- Co-founder of the Mozilla Foundation (2003)
- CEO of Mozilla (2014) — resigned 11 days later after public pressure over a donation against same-sex marriage
- Founded Brave Software (2015): a browser with built-in ad blocking and BAT (Basic Attention Token)

## Technologies shaped

- [JavaScript](../docs/nodes/javascript.md)

## Key decisions

**EICH-C001** 🟢 — JavaScript was created in 10 days per Netscape's directive "make it look like Java"; Eich took the functional core from Scheme, the object model from Self, the syntax from Java — three sources that most users of the language do not know

**EICH-C002** 🟢 — Eich did not choose the name "JavaScript" — this was a Netscape marketing decision for association with Java; the original working name was Mocha, then LiveScript

**EICH-C003** 🟠 — Brave's BAT (Basic Attention Token) is an attempt to replace the advertising model of the Internet with cryptocurrency micropayments; the same theme as the GoodNet manifesto: rent via attention as an architectural problem, not a moral one
