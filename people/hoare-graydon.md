## Known for

- Created Rust in 2006 as a personal project
- Brought functional type theory into systems programming
- Left Mozilla in 2013, before Rust 1.0 shipped in 2015

## Technologies shaped

- [Rust](../docs/nodes/rust.md)

## Key decisions

**HOARE-C001** 🟢 — started Rust from frustration with memory bugs in elevator firmware; the motivation was practical, not academic

**HOARE-C002** 🟢 — chose OCaml and Haskell as intellectual models, not C++; Rust's type system comes from functional programming, not from systems programming tradition

**HOARE-C003** 🟠 — left the project before 1.0; the language he designed was more experimental than the production system it became
