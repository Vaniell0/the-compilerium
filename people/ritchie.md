## Known for

- Created the C language (1972) at Bell Labs jointly with Ken Thompson
- Co-author of Unix (1969–1973) with Ken Thompson
- Author of «The C Programming Language» (K&R, 1978) with Brian Kernighan
- Received the Turing Award (1983) jointly with Thompson

## Technologies shaped

- [C](../docs/nodes/c.md)
- [Linux](../docs/nodes/linux.md)

## Key decisions

**RITCHIE-C001** 🟢 — C was created as portable assembly for writing Unix; the goal — one language for porting an OS between machines without rewriting from scratch; in 1973 the Unix kernel was rewritten from assembly to C

**RITCHIE-C002** 🟢 — «The C Programming Language» (K&R) established the style of language documentation: minimal book, maximal density; defined how technical books are written for 40 years ahead

**RITCHIE-C003** 🟠 — Ritchie created C as a tool for a specific task (Unix), not as a universal language; its spread beyond Bell Labs and turning into the "default language" is an unplanned outcome
